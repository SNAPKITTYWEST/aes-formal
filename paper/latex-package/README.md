# quantum-resources — Compile-Time Quantum Resource Estimator

Part of the `aes-formal` NIST submission package.

Every number in the paper is **computed at compile time** — not typed.  
Constants flow from the Lean 4 artifact. Arithmetic runs in LuaLaTeX.  
The paper is the executable specification.

## Files

| File | Role |
|------|------|
| `quantum-resources.sty` | LaTeX3/expl3 package — user macros, algorithm implementations |
| `quantum-resources.lua` | LuaLaTeX backend — full precision, arbitrary complexity formulas |

## Usage

```latex
\usepackage{quantum-resources}   % LuaLaTeX recommended

\QubitCount{shor}{2048}          % → 6146 (computed)
\TGateCount{grover}{128}         % → 1.23e24 (computed)
\PrintQuantumTable               % full comparison table
```

## Compilation

```bash
# Full precision (recommended)
lualatex main.tex

# Integer-only fallback
pdflatex main.tex
```

## Lean 4 Integration

Place `artifacts/qr_constants.json` (generated by `lean/Constants.lean`)
alongside the `.tex` file. The package loads it automatically and overrides
defaults with formally verified constants.
